# Contributing to Global Scholarship Finder

Thank you for helping students find legitimate funding opportunities.

## Good first contributions

- Add a scholarship from an official provider source.
- Verify an existing listing and update its review date.
- Improve a translation or accessibility label.
- Report an expired or misleading opportunity.
- Improve documentation or tests.

## Scholarship data rules

- Use official university, government, embassy, or recognized organization sources.
- Include both the information page and the official application URL.
- Never submit private student data.
- Do not copy long passages from provider websites.
- Explain every data change in the pull request.

Please use the issue templates for inaccurate or suspicious listings. Maintainers may reject records that cannot be independently verified.
